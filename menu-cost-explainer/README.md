# Menu Costing Explainer Video

An editable 29-second Remotion explainer for the Menu Costing app.

## Storyboard

1. Stop guessing event costs
2. Upload a PDF, photo, or pasted menu
3. Organize functions and guest counts
4. Combine food, manpower, transport, and extras
5. Review cost per cover and expected profit
6. Create a client-ready quotation

## Preview

```bash
npm install
npm run dev
```

Open `http://localhost:3000/Menu-Costing-Explainer`.

Each scene is also registered separately in Remotion Studio for easy editing.

## Render

```bash
npx remotion render Menu-Costing-Explainer out/menu-costing-explainer.mp4
```

Output: 1920×1080, 30 fps, 870 frames (29 seconds).

## Instagram Reel

The `Menu-Costing-Reel` composition is a 24-second, 1080×1920 Hinglish explainer designed for Instagram Reels.

```bash
npx remotion render Menu-Costing-Reel ../outputs/menu-costing-reel.mp4
```
